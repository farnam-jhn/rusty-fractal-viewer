#### [Mandelbrot set](https://en.wikipedia.org/wiki/Mandelbrot_set)
The Mandelbrot set is defined by the set of complex numbers $c$ for which the sequence generated by iterating the quadratic polynomial:

$$
Z(n+1) = Z(n)^2 + c
$$
starting with $Z(0) = 0 + 0i$, remains bounded as $n \to \infty$.

If $|Z(n)|$ remains bounded under iteration, $c$ belongs to the set.

#### [Julia set](https://en.wikipedia.org/wiki/Julia_set)
Julia sets share the exact same iteration function as the Mandelbrot set:

$$
Z(n+1) = Z(n)^2 + c
$$
However, the role of variables is inverted:
- In the **Mandelbrot set**, $Z(0) = 0$ is fixed, and $c$ varies across complex coordinates on the plane.
- In the **Julia set**, $c$ is a fixed complex constant (e.g., $c = -0.7 + 0.27i$), and initial $Z(0)$ varies based on the point coordinate on the complex plane.

#### [Burning ship](https://en.wikipedia.org/wiki/Burning_Ship_fractal)
The Burning Ship fractal is another escape-time fractal generated by taking absolute values of the real and imaginary components at each step:

$$
Z(n+1) = (|Re(Z(n))| + i|Im(Z(n))|)^2 + c
$$
where $c$ is a complex point in the plane. Due to the absolute value transformation, it creates non-analytic fractal structures resembling ships on fire.

#### [Tricorn](https://en.wikipedia.org/wiki/Tricorn_(mathematics))
The Tricorn (also known as the Mandelbar set) is an escape-time fractal generated using the complex conjugate of $Z(n)$:

$$
Z(n + 1) = conj(Z(n))^2 + c
$$
This introduces a three-fold rotational symmetry along with anti-holomorphic dynamics.
