I chose to transition from C++ to Rust to explore memory safety and Rust's zero-cost abstractions.
And what better way to do so than re implementing a fractal viewer in Rust using Macroquad?

Since I already built the C++ version, porting it to Rust helped answer the question "Why Rust?" in graphics and numerical calculation contexts.
